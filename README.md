# BLACKED FINAL FUSION — v1.5.0 (4f-based delivery bundle)

Mobile-first static prototype combining the three-space layout and approved interactions with the campaign assets supplied for BLACKED.

## What is included
- Exactly three main tabs: **Innerwear**, **Boyfriend 18+**, **Wellness 18+**.
- Ten separate Sanskari campaign artwork cards using the ten latest supplied images; each opens its own optimized full image.
- Innerwear reference catalogue, product detail dialogs, comparison, wishlist/save tools, product-specific manual Try-On guidance, four cutout families and an 8-frame 360° concept viewer.
- Boyfriend / Plus-One prototype with outing ideas, optional vibe selection, comfort prompts and clear consent/privacy boundaries. No real companion listings or bookings.
- Wellness 18+ self-attestation, category filters, unique concept illustrations and educational guides.
- All core images referenced locally in this bundle; the site does not need another repo's raw-image URLs to display the assets.

## Upload to GitHub Pages
1. Download a backup of the current `Brand-website-4f` repository before replacing anything.
2. Extract this ZIP. Upload the ZIP **contents** to the repository root; merge folders, and replace `index.html`, `app.js`, `styles.css` and docs when asked.
3. Keep filenames and folder paths unchanged, especially `assets/` and `assets/sanskari-gallery/`.
4. GitHub → Settings → Pages → select `main` and `/(root)` if that's the current Pages setting.
5. After deployment, open the site on Android Chrome and refresh. If old content shows, clear the site's cached files or use a private tab.

## Prototype boundaries
- This is a front-end static concept, not connected to a database, live SKU/stock, payment, checkout, user accounts or real dating/companion providers.
- Prices and category names are illustrative. The 360-degree viewer is an 8-frame generated visual demo, not a verified physical-product scan.
- The 18+ screens are self-attestation only, not formal age verification. Adult preferences stay as a local, non-submitted prototype.
- Product/campaign/reference visuals are not proof of final specifications, stock, dimensions or commercial rights. Verify rights and product claims before launch.
