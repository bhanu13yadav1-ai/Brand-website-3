# BLACKED FINAL FUSION — v1.4.0

Mobile-first static website prototype for BLACKED with three separate sections: **Innerwear**, **Boyfriend 18+**, and **Wellness 18+**.

## v1.4 highlights
- Added five latest BLACKED Sanskari Edit campaign images in `assets/new-gallery/`, optimized to WebP.
- Added a responsive five-image campaign art gallery with full-size image links.
- Made the Plus-One/Boyfriend copy bolder and more playful without turning the public-outing concept into a sexual service. An optional flirt-vibe selector works in the local preview form.
- Keeps clear consent/boundary messaging and the separate private adult preference questionnaire.
- Keeps existing innerwear catalogue, gallery/dialogs, search/filter/sort, wishlist, comparison, style tools, Fit Detective, Fit Passport, manual Try-On guide and 8-frame 360° concept demo.

## Install into existing GitHub Pages repo
Use `BLACKED-INNERWEAR-FIT-STUDIO-v1.4.0-CHANGED-FILES.zip`. Back up your current repository first, replace the listed HTML/CSS/JS/docs files, then upload `assets/new-gallery/`. Do not delete or re-upload the old image files.

See `UPDATE-MANIFEST.md` for exact steps and limitations.

## Important prototype boundaries
- No AI API, database, account system, checkout, inventory feed, actual orders, live dating matches, real companion providers, bookings, payment or message sending.
- The 360° viewer uses generated concept frames rather than a photographed physical product scan.
- The age gates are front-end self-attestation only.
- Product/campaign art does not verify SKU identity, supplier claims, stock, fabric, size, or fit.
- GitHub access was read-only for this build; no commit/deployment was performed.
