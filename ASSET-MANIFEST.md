# BLACKED INNERWEAR v1.1.0 — Asset manifest

No image assets were added, removed or edited in v1.1.0. The full release reuses all image assets from v1.0.0 unchanged. The changed-files patch therefore contains no images.

Campaigns, design concepts and external-brand reference imagery are not confirmed sellable inventory. External reference assets stay labelled as references and are not embedded from any external website.

## Existing asset groups
- `ref-01` through `ref-10`: original user-supplied BLACKED references.
- `owner-ref-*`: user-supplied campaign/design references.
- `design-11` through `design-14`: design concept posters and local concept garment-detail views.
- `external-ref-syrn-*`: user-supplied external-brand reference images; reference only, not BLACKED stock.
- `wellness-hero-art.svg`: original, non-explicit BLACKED Intimate Wellness decorative illustration.

Refer to `index.html` and `app.js` for product-to-image mappings. A product detail view is enabled only when a local image has been explicitly mapped for that item; missing details are not substituted with an unrelated image.
